# Format Clock "Pagi Bener" HITS Unikom Radio

Sumber: foto cetakan "FORMAT CLOCK PAGI BENER" (rundown on-air HITS, 06.00-09.00), dibagikan Favian 15 Okt 2026.

## Status pemakaian
- Ini rundown asli siaran on-air radio HITS.
- Menurut pembimbing, rundown untuk live TikTok sama dengan rundown on-air radio HITS. Format ini dipakai sebagai acuan rundown sistem penyiar AI.
- Live TikTok ditargetkan 1 jam versi ringkas; lihat RUNDOWN-LIVE-1-JAM-DRAF.md.

## Notasi (interpretasi, belum dikonfirmasi ke HITS)
- `('9)`, `('10)`, `('25)` dan sejenisnya: durasi dalam detik.
- `(1)`, `(3)`: durasi dalam menit (atau jumlah slot).
- Baris jam seperti `06.15` adalah penanda kuartal jam.
- Setiap jam terbagi empat kuartal; kuartal 2-4 selalu dibuka SMASH VERSI, 2x SPOT/ADLIBS, JINGLE HITS.

## Klasifikasi elemen
- GREETINGS ARTIS: audio rekaman artis (statis).
- SPOT/ADLIBS (iklan) dan ICE BREAKING: perlu TTS.
- TALK: improvisasi penyiar dari dokumen Tema.
- SMASH, TIME SIGNAL, JINGLE, IMAGE/MASHUP, BUMPER, P.S.A: audio statis.
- LAGU: diputar dari sumber musik.
